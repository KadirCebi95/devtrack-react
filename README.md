# DevTrack

A React application developed to practice modern frontend development concepts through a real project.

> 🚧 Work in Progress — New features are being added regularly.

## Current Features

- Reusable React components
- Props and object destructuring
- Dynamic list rendering with `map()`
- Unique keys for list items
- Follow/unfollow interaction with `useState`
- Responsive profile card layout

## Technologies

- React
- JavaScript
- Vite
- CSS
- Git & GitHub

## Planned Features

- Developer search
- Role filtering
- Add and delete profiles
- Empty states
- LocalStorage
- Improved accessibility and responsive design
